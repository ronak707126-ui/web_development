# 📱 Mobile Hub

A modern and responsive **Mobile Hub** website built using **HTML5, CSS3, Bootstrap 5, and Font Awesome**. The website showcases the latest smartphones from top brands with a clean interface, responsive design, customer reviews, and direct links to official brand websites.

---

## 📖 About the Project

**Mobile Hub** is a front-end web application designed to provide users with an engaging platform to explore the latest smartphones. The website features a modern layout with smooth navigation and highlights various smartphone brands, their features, and shopping links.

This project demonstrates responsive web design principles using HTML, CSS, and Bootstrap, making it suitable for desktops, tablets, and mobile devices.

## 🚀 Getting Started

### Clone the Repository

```bash

```

### Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it using **Live Server** in Visual Studio Code.

No additional installation or dependencies are required.
