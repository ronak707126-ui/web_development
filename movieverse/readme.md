# 🎬 Filmy Verse

Filmy Verse is a modern movie search website built with **HTML, CSS, and JavaScript**. It uses the **OMDb API** to fetch real-time movie information including posters, ratings, release dates, genres, and plot summaries.

---

## ✨ Features

- 🔍 Search movies by title
- 🎬 Live movie data from the OMDb API
- ⭐ IMDb ratings
- 📅 Release year
- 🎭 Genre information
- 📝 Movie overview
- 📱 Responsive design
- 🎨 Modern streaming platform inspired UI
- ❤️ Favorites section (Local Storage)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OMDb API
- Font Awesome
- Google Fonts (Times New Roman)

---

## 🔑 OMDb API

This project uses the **OMDb API** to fetch movie data.

Get your free API key here:

👉 https://www.omdbapi.com/apikey.aspx

Replace the API key in `script.js`:

```javascript
const API_KEY = "YOUR_API_KEY";
```

---

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/filmy-verse.git
```

2. Open the project folder.

3. Add your OMDb API key in `script.js`.

4. Open `index.html` using Live Server or any browser.
